# 🥗 Food Expiry Tracker

A full-stack, multi-device web application designed to help users track food items, monitor expiration dates, and reduce household food waste.

---

## 🚀 Key Features

- **Item Tracking:** Easily add, edit, and delete food items with specified expiration dates.
- **Dynamic Notifications:** Visual cues and alerts for items nearing expiration or already expired.
- **Real-Time Database Sync:** Powered by Firebase Firestore for seamless data updates across multiple devices.
- **Interactive UI:** Clean dashboard with edit modal support for managing inventory on the go.

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite), JavaScript / TypeScript, Tailwind CSS
- **Backend / Database:** Firebase Firestore, Python, SQLite
- **Deployment:** Vercel
